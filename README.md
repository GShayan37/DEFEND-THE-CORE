# 🛡️ DEFEND THE CORE

**DEFEND THE CORE v3.60.11** is a mobile-friendly HTML tower defense game where your mission is simple:

> **Protect the Core and survive the enemy waves!**

## 🎮 About the Game

Build powerful defensive towers around the battlefield and stop enemies from reaching the Core. Earn coins by defeating enemies, upgrade your defenses, choose different strategies, and survive increasingly difficult waves.

The game features multiple maps, difficulty levels, challenges, tower types, enemy types, bosses, achievements, and an Endless Mode.

## ⚔️ Features

- 🏰 Tower defense gameplay
- 🔫 7 different defensive towers
- 👾 Multiple enemy types with unique abilities
- 👑 Powerful boss enemies
- 🗺️ 3 different maps
- 🎯 Normal, Easy and Hard difficulties
